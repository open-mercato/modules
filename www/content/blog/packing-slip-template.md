A packing slip tells the recipient what is in _this shipment_. If a customer ordered ten rolls and you packed seven, put seven in the shipped column and three in outstanding. Use the template below for the box, or choose Save as PDF in your browser's print dialog.

<om-embed name="blog-packing-slip-template-1"></om-embed>

## What to put on a packing slip

Use a sender and recipient that the receiving desk will recognize, the customer's order reference, and a shipment reference that identifies this dispatch. For each line, include an item name or SKU, the unit of measure, the quantity ordered, and the quantity actually inside. If the unit is a case of twelve, write “cases of 12.” Seven cases and seven individual units can both look like a perfectly plausible entry.

Prices and payment terms usually belong on the invoice. The packing slip answers a receiving question, the carrier label routes a parcel, and the invoice requests payment. Each can carry the same order number so a person can follow the documents back to the same sale.

## How to write the second slip for a split shipment

Keep order `PO-1042` on both slips. Give the first parcel shipment reference `PO-1042-1`. It shows ten ordered, zero sent earlier, seven in this box, and three outstanding. For the second dispatch, change the shipment reference to `PO-1042-2`. Enter ten ordered, seven sent earlier, and three in this box. Outstanding is now zero.

**Outstanding = ordered − shipped earlier − in this box.** A negative result is worth catching before the slip is printed. Check whether someone entered the first seven in both shipment columns. If a customer canceled the remaining quantity, revise the order first so the paperwork reflects the agreed quantity.

## What changes when several people pack at once?

For scannable internal item or bin labels, use the same SKU consistently on the slip and on the label. [Generate and print a Code 128 label for a SKU.](/blog-posts/code-128-barcode-generator)

A printable form works while one packer can see the order and everything already dispatched. Once two stations can pack the same order, both need the same shipment history. Otherwise two accurate-looking slips can promise the same remaining three units.
